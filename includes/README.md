# includes

Bestanden in deze map worden niet als losse pagina's op de site gezet, maar in pagina's geplakt via `pymdownx.snippets` (ingesteld in `zensical.toml`).

## `afkortingen.md` — woordenlijst

Dit bestand wordt automatisch onder **elke** pagina geplakt. Iedere afkorting die erin staat krijgt op de hele site een stippellijn met uitleg als je eroverheen gaat (of erop tikt op je telefoon).

Een afkorting toevoegen: zet een nieuwe regel in de vorm

```text
*[AFK]: Uitleg in gewone taal
```

- Hoofdletters tellen mee: `VvE` en `VVE` zijn verschillende afkortingen.
- Houd de lijst op alfabetische volgorde.
- Zet er geen andere tekst of opmerkingen in; die zouden op elke pagina verschijnen.
